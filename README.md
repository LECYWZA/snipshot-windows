# SnipShot（Windows 版）

参考原 Ubuntu 版 `snipshot` 的逻辑与需求复刻的 Windows 版本：截图 / 标注 / 贴图 / 截屏翻译 / 文字提取 / 剪贴板历史 / 屏幕录制。

## 运行

- 系统：Windows 10 / 11 x64
- 免安装：解压后直接运行 `SnipShot.exe`（托盘常驻）
- 录屏需要 `ffmpeg.exe`：已放在程序目录，或在“设置→FFmpeg 路径”中指定
- 首次运行如遇 SmartScreen 提示，选择“更多信息 → 仍要运行”

## 快捷键（Windows 默认）

| 功能 | 快捷键 |
|---|---|
| 截图 | `Ctrl+Alt+S` |
| 固定贴图（贴出上一次截图/选区） | `Alt+Shift+D` |
| 隐藏/显示所有贴图 | `Alt+Shift+H` |
| 截屏翻译 | `Alt+Shift+Q` |
| 文字提取 | `Alt+Shift+W` |
| 剪贴板历史 | `Alt+Shift+V` |
| 开始/停止录屏 | `Alt+Shift+R` |

> 原版的 F1/F2/F3/Alt+Q 在 Windows 上常被 Snipaste、Quicker 等占用，所以默认改成 Alt+Shift 组合。
> 快捷键在“设置→快捷键”里修改：**点击输入框后直接按键盘组合**（不是打字），左侧勾选控制是否启用。
> 录入时会立即检测冲突，被其他程序占用会提示“重新录入 / 仍然保存”。

## 截屏翻译（原位覆盖）

1. 按 `Alt+Shift+Q` 框选需要翻译的区域；
2. 程序用 Windows 自带 OCR 取每一行文字与坐标，逐行翻译；
3. 译文直接覆盖在原文位置；
4. 贴图顶部工具条可切换 `原文 / 译文`、选择目标语言（简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Русский）；
5. 右键菜单同样可以切换原文/译文、选择翻译语言、显示/隐藏工具条与文本栏、显示边框；
6. “文本栏”在图片右侧、与图片同一窗口，内容可编辑、可选中复制，不影响图片上的覆盖效果。

默认目标语言在“设置→默认翻译目标语言”里配置；贴图里改语言只影响当前这张图。

## 文字提取（OCR）

`Alt+Shift+W` 框选后，右侧文本栏直接给出按阅读顺序提取的文字，可编辑、复制、另存。

OCR 使用 Windows 系统 OCR（Windows.Media.Ocr）。若提示没有 OCR 语言包：
设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项 → 安装“光学字符识别”。

## 剪贴板历史

- 后台监听系统剪贴板（文本/图片），支持搜索、固定、编辑、删除、清空未固定；
- 顶部“当前 / 固定”两个页签；条目右键可复制、编辑文字、固定/取消固定、查看大图、删除；
- 双击图片可直接放大预览；
- **键盘操作**：搜索框按 `↓` 进入列表，`↑/↓` 选择，`Enter` 直接粘贴回打开剪贴板之前的输入框；
- 历史保存在 `%APPDATA%\SnipShot\clipboard`；
- 设置里可关闭或调整保留条数。

## 开机自启

“设置 → API / 保存 → 开机自动启动（当前用户）”勾选即可：
在 `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\SnipShot.lnk` 创建快捷方式，取消勾选会删除。

## 录屏

- 使用 ffmpeg `gdigrab` 抓取整个虚拟桌面，输出 MP4/H.264；
- 快捷键或托盘菜单开始/停止；
- 输出目录在“设置→录屏保存目录”；
- 录制期间阻止系统息屏/睡眠。

## AI 接口

项目不内置任何密钥。首次使用请在“设置 → API”填写任意 OpenAI 兼容接口：

- 地址：例如 `https://api.openai.com/v1`
- API Key：你自己的密钥（只保存在本机注册表）
- 模型：例如 `gpt-4o-mini`，或任何支持图片输入的 OpenAI 兼容模型

截屏翻译/文字提取会把框选图片以 `image_url`（data URI）形式发送到 `/chat/completions`，
因此所用模型必须支持图片输入。

内网自建网关也可以，只要兼容 OpenAI 的 `chat/completions` 协议。

## 源代码构建

需要：Visual Studio 2022（MSVC x64）、Qt 6.8.3 MSVC2022、CMake。

```bat
build.bat
```

生成 `build\snipshot.exe`。打包绿色版：

```bat
deploy.bat
```

输出 `dist\SnipShot-win64.zip`。

## 已知限制

- 多屏混合 DPI（不同缩放比例）尚未做完整回归，建议先把各屏缩放设为一致；
- OCR 精度受系统 OCR 语言包与文字大小影响，过小字号可能识别不准；
- 录屏为全桌面录制，暂不支持框选区域；
- 翻译/OCR 需要能访问内网 AI 网关。
